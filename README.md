# Movie_Tracker
A full-stack movie tracking and discovery platform for managing personal movie libraries, ratings, watch history, statistics, and eventually personalized recommendations.

## Current Features
- User registration and login
- Individual user movie libraries
- PostgreSQL database
- IMDb/Letterboxd movie history importing
- TMDB integration for movie information

## Planned Features
- Statistics on user's watch history
- User-selected streaming services
- Personalized movie recommendations based on watch history and ratings
- AI recommendation chatbot for natural-language movie requests

## Tech Stack
- React
- Python
- FastAPI
- PostgreSQL
- TMDB API
